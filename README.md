# tr-epub-hyphenator
Calibre plugin that automatically inserts proper Turkish hyphenation points into EPUB books, improving text justification and reading layout on e-readers.

## Features

- Adds Turkish soft hyphenation to EPUB files
- Improves spacing and justification on supported e-readers
- Preserves original EPUB structure

## Installation

1. Download the latest `.zip` file from the **Releases** section.
2. Open Calibre.
3. Go to **Preferences**.
4. Under **Advanced**, click **Plugins**.
5. Click **Load plugin from file**.
6. Select the downloaded `.zip` file.
